# 趣味猜女声优器 · QQ 机器人版

把桌面版（`main.py`）和网页版（`web_app.py`）那套猜声优玩法搬到 QQ 群里：
**@机器人说「猜声优」→ 选企划 → 看图/看名字作答 → 答对答错不同回应 → 12 题结算**。

玩法规则与原版**完全一致**（多企划混选、12 题满分 120、两种题型交替、
正确答案不重复、XD 模式正确率＜50% 得分归零），只是把交互界面换成了 QQ 聊天。

---

## 一、这东西是怎么跑起来的

```
     ┌─────────────┐        ① QQ 收发消息           ┌──────────────────┐
     │   QQ 客户端  │ ◄───────────────────────────► │  NapCat / LLOneBot │
     └─────────────┘      （协议解析、登录、风控）    │   （QQ 端实现）     │
                                                     └────────┬─────────┘
                                        ② OneBot v11 正向 WebSocket
                                            ws://127.0.0.1:3001
                                                              │
                                                     ┌────────▼─────────┐
                                                     │  qqbot/bot.py     │
                                                     │  出题 / 判题 / 计分 │
                                                     └────────┬─────────┘
                                                     ┌────────▼─────────┐
                                                     │ ../assets/ 图片素材 │
                                                     └──────────────────┘
```

- **本项目的 `bot.py` 不直接连 QQ**，它只说 [OneBot v11](https://github.com/botuniverse/onebot-11) 这套通用协议。
  真正负责登录 QQ、解析消息、对抗风控的是 **QQ 端实现**，推荐 [NapCat](https://github.com/NapNeko/NapCatQQ)（也可用 LLOneBot / Lagrange，协议一样，只改端口）。
- 好处：QQ 端实现被换掉时，`bot.py` 一行都不用改。

### 文件说明

| 文件 | 作用 |
| --- | --- |
| `game.py` | **纯游戏逻辑**：读素材、出题、判题、结算。不含网络与 UI，可单独测试 |
| `image_utils.py` | 图片缩放白底填充（与原版一致）＋ 转成 QQ 可发送的图片消息段 |
| `bot.py` | **机器人主程序**：连 OneBot、解析 @ 与指令、驱动对局状态机 |
| `config.py` / `config.example.json` | 配置加载与示例 |
| `test_game.py` | **离线自测**，不连 QQ 也能把 12 题流程跑一遍（71 项断言） |
| `mock_onebot_server.py` | **假 OneBot 服务器**，不装 QQ 也能在终端里调戏机器人 |
| `start_bot.bat` / `start_bot.sh` | 一键启动（自动装依赖、自动生成 config.json） |

## 二、快速开始（Windows）

### 第 1 步：装一个 QQ 端实现（NapCat）

1. 到 [NapCat 仓库](https://github.com/NapNeko/NapCatQQ) 下载 **一键安装脚本**（`NapCat.Installer`），
   或直接下载 NapCat.Shell 压缩包解压。
2. 按官方文档启动，用手机 QQ 扫码登录（登录后这个 QQ 号就成了你的机器人）。
3. 在 NapCat 的 **WebUI → 网络配置** 里新增一个 **「WebSocket 服务器」**：
   - 端口填 `3001`（NapCat 默认值，若被占用改成别的，比如 3001→3101）
   - **记住这里设置的 Token**，等下要填进 `config.json`
   - 启用后确认状态是「运行中」
4. 用一个小号把机器人 QQ 加为好友 / 拉进测试群。

> ⚠️ 机器人账号有被腾讯风控的风险，**强烈建议用小号**，别用主号。

### 第 2 步：装依赖

```bash
# 在项目根目录
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r qqbot/requirements.txt
```

也可以直接双击 `qqbot\start_bot.bat`，它会自动装依赖并生成配置文件。

### 第 3 步：写配置

把 `qqbot/config.example.json` 复制成 `qqbot/config.json`，至少确认这两项：

```json
{
  "onebot_ws_url": "ws://127.0.0.1:3001",
  "access_token": "你在 NapCat 里设的 Token（没设就留空）"
}
```

> 如果 NapCat 和本项目不在同一台机器上，把 `127.0.0.1` 换成 NapCat 所在机器的 IP，
> 并确认 `image_send_mode` 保持 `"base64"`（见第五节）。

### 第 4 步：启动

```bash
cd qqbot
python bot.py
```

看到下面这样就说明连上了：

```
2026-10-10 22:00:00 [INFO] 已加载 9 个企划：BangDream、RevueStarlight、...
2026-10-10 22:00:00 [INFO] 图片发送模式：base64
2026-10-10 22:00:00 [INFO] 正在连接 OneBot：ws://127.0.0.1:3001
2026-10-10 22:00:00 [INFO] ✅ 已连接，开始接收消息
```

断开后会自动重连（1s→2s→4s…最多 30s），所以 NapCat 重启了也不用管。

### 第 5 步：在群里玩

```
你：@机器人 猜声优
机器人：📚 当前可玩的企划：
        1. BangDream
        2. RevueStarlight
        ...
你：1 2 xd                     ← 多选用空格隔开，xd 开启挑战模式
机器人：🎬 开局！企划：BangDream、RevueStarlight
        共 12 题，每题 10 分
        😈 XD 模式已开启（正确率低于 50% 得分归零）
机器人：【第 1/12 题 · 看名选图】
        请从下面 4 张图片中选出「藤都子」
        （依次对应 A、B、C、D）
机器人：A：[图片]   B：[图片]   C：[图片]   D：[图片]
你：C                          ← 对局中作答不用 @ 机器人
机器人：🎯 完全正确！「藤都子」没跑了！　（当前得分 10）
```

## 三、指令一览

| 指令 | 说明 |
| --- | --- |
| `@机器人 猜声优` | 开一局（也可用：猜谜 / 开始 / 来一局 / 玩） |
| `@机器人 企划` | 查看全部企划清单 |
| `@机器人 帮助` | 显示玩法说明 |
| `@机器人 状态` | 查看当前进度、分数、已用时间 |
| `@机器人 结束` | 结束当前对局 |
| `@机器人 再来` | 结束后直接开新的一局 |
| 回复 `1 3` | **选企划阶段**：按序号多选，支持 `1、2，3` 等混用标点 |
| 回复 `1 2 xd` | 选企划并开启 XD 模式；回复 `全部` 可全选 |
| 回复 `A` / `1` | **答题阶段**：作答（大小写不敏感，也认 `选C`、`答案是D`、`B。`） |

几个细节：

- **群里必须 @ 机器人**才认指令（避免误触发）；对局中的作答**不需要 @**，直接回 `A` 就行。
- 也支持前缀触发，不用 @：`#猜声优`、`/帮助`、`！企划`（前缀可在配置里改）。
- **私聊无需 @**，直接发指令即可。
- 每人每群一个**独立对局**，多人同时玩互不干扰。
- 机器人对其他人的普通聊天内容**一律不理会**，只有指令和「你自己对局里的作答/选择」才会被响应。

## 四、不装 QQ 也能调试

### 方式 A：假 OneBot 服务器（推荐，能看真实协议收发）

开两个终端：

```bash
# 终端 1：启动假服务器（假装自己是 NapCat）
cd qqbot
python mock_onebot_server.py

# 终端 2：启动机器人
cd qqbot
python bot.py
```

回到终端 1，像群友一样输入就行：

```
> 猜声优            ← 模拟「@机器人 猜声优」
> 1 2 xd            ← 模拟选企划
> A                 ← 模拟作答
> /n 你好           ← 前面加 /n 表示「不 @ 机器人」说话
> /p 帮助           ← 前面加 /p 表示私聊
> quit
```

机器人发来的图片会**自动存到 `qqbot/mock_dump/`**，可以直接打开看图片对不对。

非交互跑一遍脚本（CI / 快速验证）：

```bash
python mock_onebot_server.py --script "猜声优|1 2 xd|A|1|B|2"
```

### 方式 B：离线自测（不碰网络，最快）

```bash
cd qqbot
python test_game.py
```

覆盖 71 项断言：素材加载、12 题生成、题型交替、正确答案不重复、全对/全错/XD 斩杀、
@ 识别与 CQ 串解析、企划序号解析、作答解析、图片段格式，以及**端到端模拟整局对话**

## 五、配置项说明（`qqbot/config.json`）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `onebot_ws_url` | `ws://127.0.0.1:3001` | OneBot 正向 WebSocket 地址。Lagrange 默认 `ws://127.0.0.1:8080` |
| `access_token` | `""` | NapCat 里设的 Token，没设就留空 |
| `use_system_proxy` | `false` | 是否走系统代理环境变量，见下方「代理陷阱」 |
| `assets_dir` | `../assets` | 图片素材目录，相对 `qqbot/`。想指向别处就写成绝对路径 |
| `image_send_mode` | `base64` | 图片发送方式，见下方对比 |
| `image_size` | `400` | 发送图片的边长（像素），越小消息越轻 |
| `send_interval` | `0.4` | 连发多张图片的间隔秒数，防触发风控 |
| `require_at_in_group` | `true` | 群里是否必须 @ 机器人才认指令 |
| `allow_plain_answer` | `true` | 对局中是否允许直接回复 A/B/C/D（不用 @） |
| `enable_group_chat` | `true` | 是否响应群聊 |
| `enable_private_chat` | `true` | 是否响应私聊 |
| `command_prefixes` | `["#","/","！","!","。"]` | 除 @ 之外可用的指令前缀 |
| `session_ttl` | `3600` | 对局超过多久无活动自动回收（秒） |
| `max_sessions` | `100` | 同时进行的对局上限，防刷 |
| `log_level` | `INFO` | 日志级别，排查问题时改 `DEBUG` |

### 图片发送方式怎么选

| 模式 | 适用场景 | 优点 | 缺点 |
| --- | --- | --- | --- |
| `base64`（默认） | 机器人部署在**另一台**服务器上 | 不依赖 QQ 端能否读到图片文件，最稳 | 消息体较大（单图 30~80KB） |
| `file` | NapCat 与项目**在同一台机器** | 秒发、不占流量 | QQ 端读不到文件路径时会发不出图 |

> 图片发不出来、只显示 `[图片]` 占位时，先把 `image_send_mode` 在两种模式间对调试试。

### 代理陷阱（务必留意）

`websockets` 15 及以上版本**会自动读取 `HTTP_PROXY` / `HTTPS_PROXY` 环境变量**。
国内开发机常常开着代理（Clash / V2Ray / 公司代理），这会导致连**本机** NapCat 的
`ws://127.0.0.1:3001` 也被塞进代理转发，报出这类看不懂的错：

```
连接断开：proxy rejected connection: HTTP 502，2 秒后重连
```

本项目**默认已显式关闭代理**（`use_system_proxy: false`），正常情况不需要管。
只有在 NapCat 部署在远端、且必须经代理才能访问时，才把它设为 `true`。

## 六、常见问题

**Q：启动报「连接断开 … 秒后重连」，一直连不上？**
A：八成是端口或 Token 对不上。核对 NapCat WebUI 里那个「WebSocket 服务器」的端口和 Token，
以及它是否处于「运行中」；先确认 `ws://127.0.0.1:3001` 能通（可用 `mock_onebot_server.py` 顶替 NapCat 验证 `bot.py` 本身没问题）。

**Q：@了机器人但完全没反应？**
A：① 确认是 `@` 到了机器人账号本身（不是 @ 别人）；② 群里 `require_at_in_group` 为 `true` 时必须 @；
③ 看 `bot.py` 的日志有没有收到消息；④ 机器人被禁言了。

**Q：图片发出去是空白 / 发不出去？**
A：把 `image_send_mode` 换成另一种试试；或把 `image_size` 调小到 `300`。

**Q：报「所选企划的声优不足 4 位」？**
A：本游戏每题要 4 个选项，所以单个企划里**至少要有 4 位有效声优**。多选几个企划，
或检查 `assets/` 下的目录是否符合 `企划/001-声优名/图片` 的结构。

**Q：机器人会不会抢答别人的消息？**
A：不会。作答只认「发起该对局的人」在自己会话里的回复，且普通聊天内容一律不响应。

**Q：怎么让它开机自启 / 后台常驻？**
A：Linux 用 `systemd`（`ExecStart=/path/.venv/bin/python /path/qqbot/bot.py`，`Restart=always`）；
Windows 可以把它写成计划任务，或用 `nssm install`。配合断线自动重连，基本不用管。
